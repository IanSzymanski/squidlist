# Repository skills

The directories under `skills/` are the canonical, shareable Codex skills for this repository. Keep them version-controlled so every developer can use the same project guidance.

## Fresh checkout

Before the installer skill is present in a local agent, read [install-repo-skills/SKILL.md](install-repo-skills/SKILL.md) directly from the checkout and ask the agent:

> Use the repository instructions at `skills/install-repo-skills/SKILL.md` to install all valid repository skills into the current agent's local skills directory.

After installation, the skill can be invoked as `$install-repo-skills`. Existing local skills must not be replaced without the developer's explicit verbal confirmation.
